# 화면과 계산 규칙

값의 출처, 조회 시각과 원본 관측 시각을 구분한다. 엔진의 장부 수량, 계좌 관측, 주문 접수와 체결은 서로 다른 데이터다.

## 주요 화면

| 화면 | 경로 | 데이터 |
|---|---|---|
| Dashboard | / | 인증된 핵심 요약, 세 개의 지표, QQQ/SMA200 미리보기, 최근 주문 5건 |
| Strategy | /strategy | 전략 설명, 현재 상태와 동일 신호의 판단 근거 |
| Market | /market | 종목·기간·봉 간격별 차트와 신호/주문/체결 마커 |
| Trades | /trades | 최신 주문 범위의 필터·정렬·페이지네이션 |
| 거래 상세 | /trades/주문ID | 주문 투영과 실제 체결·이벤트 |
| Portfolio | /portfolio | 장부 수량, 자금, 예산, 연도별 손익과 세무 원장 |
| Engine | /engine | 생존·준비·DB/API/schema·마지막 평가·진단 |
| 합성 데모 | /demo 와 동일 하위 경로 | 공개 합성 fixture. 실제 API 요청 없음 |

## 자산과 손익

- 계좌 평가금액은 daily_snapshots에서 실제 at이 있는 최신 관측의 equity와 currency를 사용한다. 현재 평가로 간주하지 않는다.
- 평가손익과 SPYM 평균 매입 단가는 API가 제공하지 않아 미제공으로 표시한다. TQQQ 사이클 entry_price는 전체 계좌의 세무 평균원가와 구분한다.
- 확인된 실현손익은 annual-pnl에 포함된 연도의 verified_broker_pnl_krw 합계다. pending_count와 외부 손익 미반영을 함께 표시한다. 모든 기간과 전체 증권사의 확정 손익을 의미하지 않는다.
- profit_cash는 남아 있는 익절 수익금 장부다. 누적 실현손익으로 표시하지 않는다.
- 실제 기준 예수금, 추정 예수금, 주문 가능 한도와 funding_debit을 따로 표시한다. 동일 현금 자산으로 합산하지 않는다. RP와 출금 가능 금액을 추정하지 않는다.
- SPYM 예산은 spym_lots의 잔액 합계다. available_day 전 금액도 포함하므로 현재 주문 가능한 예산이라는 표현을 사용하지 않는다.
- 원본 금액은 문자열로 유지한다. 표시용 합계와 임계값은 decimal.js 100자리 정밀도로 계산한다. 차트 좌표에만 Number를 사용한다. 툴팁에는 원본 가격을 사용한다.

## 신호, 주문, 체결

QQQ는 전략 판단용이다. QQQ 차트에는 신호만 표시한다. 신호 거래일과 signal_price, signal_sma_value, effective_buy_buffer/effective_sell_buffer를 사용한다. 매수/매도 기준은 `SMA × (1 ± 보존된 완충 폭)`으로 계산한 표시값이며 당시 근거로만 사용한다. 프론트엔드는 신호를 생성하거나 매매를 판단하지 않는다.

현재 완충 폭은 status.assessment.trend_buffer, 익절 단계는 현재 전략 버전의 config_snapshot에서 읽는다. 현재 버전 설정이 조회되지 않으면 임의의 기본값을 적용하지 않는다. 단계 완료는 cycle.completed, 실행 불가는 cycle.unavailable을 사용한다. 보유 잔량과 최초 매수 단가를 별도로 표시한다.

TQQQ/SPYM 차트는 ORDER_SUBMITTED 이벤트를 사각형, FILL을 원으로 표시한다. 전송 시각에 확인된 지정가가 없는 시장가 주문은 y축 가격을 만들지 않는다. QQQ 신호는 마름모다. 주문 상태와 실제 체결 수량은 별도 정보다.

FILL은 trade_id와 broker_execution_id로 중복을 제거한다. 개별 fill_quantity만 사용하며 cumulative_filled_quantity를 다시 합산하지 않는다. 과거 trade_history의 FILL을 신규 이벤트와 중복 집계하지 않는다. UNKNOWN은 미확정, CANCEL_PENDING은 취소 요청 중, CANCELLED는 취소 완료다.

## 시각과 갱신

원본 이벤트는 timezone을 가진 UTC 시각이다. 사용자는 Asia/Seoul과 America/New_York를 선택할 수 있다. Intl의 IANA 시간대를 사용하므로 DST를 고정 오프셋으로 처리하지 않는다. 테이블 기간은 선택한 시간대의 주문 생성일에 적용한다. 상세에서는 실제 체결 시각을 따로 제공한다.

일봉 마커는 미국 거래일에만 매핑하고 분봉은 실제 발생 시각으로 배치한다. 정규장, 프리마켓, 애프터마켓은 제공된 session으로 표시한다. 실데이터의 휴장일과 세션을 요일이나 고정 시간으로 생성하지 않는다. 실제 시세가 연결되지 않았으므로 거래소 일정 처리가 검증됐다고 주장하지 않는다.

수동 새로고침과 선택형 60초 자동 갱신을 제공한다. 자동 갱신은 보이는 탭에서만 실행한다. 차트의 갱신 버튼은 별도로 시세를 조회한다. 시세 Mock 캐시는 30초이며 fixture 기준 시각은 고정이다. 엔진 last_check_at이 120초 이상 오래되면 관측 오래됨을 표시한다.

조회 실패 시 이전 정상 결과를 현재 상태로 보이지 않는다. 서버 오류와 원본 데이터 미제공을 구분한다. 엔진 프로세스 생존, 업무 연결, 실거래 설정과 주문 활성화도 별도로 표시한다.

## 초안의 범위

차트는 OHLCV가 제공될 때 종가 선과 거래량을 표시하는 첫 초안이다. 캔들스틱, 확대/이동, WebSocket, 전체 이력 검색, 브로커 종목별 평가와 원화 환산은 추가 구현 대상이다. 최대 조회 범위는 [조회 계약](API_INTEGRATION.md)을 따른다. 실제 연결 전에는 공개 Mock으로 화면 구조를 검토한다.

메인에는 필터, 전체 거래 표, 세무 원장과 오류 상세를 표시하지 않는다. 기존 `/dashboard/*`, `/demo/orders`, `/demo/health`는 호환용으로 유지하고 링크는 새 경로를 사용한다. 전략 설명과 데이터 한계는 [전략 문서](STRATEGY.md)를 따른다.
