# TQQQ 200d MA Strategy Dashboard 전략 설명

거래 엔진의 [전략 기준 명세 1.3](https://github.com/DaLae37/tqqq.dalae37.com-engine/blob/main/docs/STRATEGY.md), `policies.py`, `repository.py`, `engine.py`의 구현을 기준으로 한다. 확인한 명세의 Git blob은 `718c5b55df8a64c78ac037422e8bda5ff4f21e35`다. 아래 기본 규칙에서 문서와 구현의 충돌은 발견하지 않았다. 실제 설정과 현재 상태는 엔진 API를 따른다.

## 종목과 기준 가격

QQQ는 신호 판단용, TQQQ는 추세 매매용, SPYM은 장기 적립용이다. TQQQ 자체의 200일 이동평균선을 사용하는 전략이 아니다.

SMA200은 해당 거래일까지 연속된 최근 200개 거래일의 확정 정규장 종가 평균이다. 미국 거래일을 기준으로 현재 거래일 종가를 포함한다. 자료 부족·누락·중복·미확정·다른 세션·혼합 조정 기준이면 신호를 만들지 않는다. 시간외 가격을 신호 입력에 사용하지 않는다.

## 추세 조건

| 조건 | 신호 |
|---|---|
| 미보유이고 QQQ 종가 > SMA200 × (1 + 현재 매수 완충 폭) | TQQQ 매수 |
| 보유하고 QQQ 종가 < SMA200 × (1 − 현재 매도 완충 폭) | 잔여 TQQQ 전량 매도 |

기본 완충 폭은 각각 1%다. 기준선과 같거나 완충 구간이면 기존 상태를 유지한다. 보유 중 추가 신규 매수는 금지하며 최초 주문의 부분 체결 복구는 구분한다. 기본 전략에는 별도 고정 손절률이 없다. 신호는 주문이나 체결을 의미하지 않는다.

## 동적 완충 폭

TQQQ 신규 매수의 첫 실제 체결과 SMA 전량 매도로 실제 잔량이 0이 된 체결마다 양쪽 완충 폭을 각각 1%포인트 확대한다. 같은 최초 매수의 후속 부분 체결, 분할 익절, SPYM 거래와 주문 접수·취소는 확대 횟수에 포함하지 않는다.

확대분은 마지막 해당 체결부터 30 × 24시간 유지한다. 기간 중 새 해당 체결은 확대분을 누적하고 만료를 다시 30일 뒤로 갱신한다. 만료 시각 이상에서는 기본 ±1%로 판단한다. 전량 매도로 사이클이 종료돼도 만료 전에는 확대분을 초기화하지 않는다.

설명용 예시는 기본 101%/99%, 확대 1회 102%/98%, 확대 2회 103%/97%다. 실제 현재값을 대신하지 않는다.

## 분할 익절

정규장 TQQQ 현재가를 사이클 최초 매수의 실제 가중평균 체결 단가와 비교한다. 최초 매수 처리가 끝나기 전에는 익절하지 않는다.

| 수익률 이상 | 실제 잔여 수량의 매도 비율 |
|---|---|
| +10% | 10% |
| +25% | 10% |
| +50% | 10% |
| +100% | 50% |
| +200% | 50% |
| 이후 +100%마다 | 50% |

정규장에서만 판단·실행하고 종가를 기다리지 않는다. 여러 단계를 넘으면 낮은 단계부터 실제 체결·잔량을 확인한다. 수량은 내림하며 0주이면 주문하지 않고 해당 사이클의 실행 불가 단계로 기록한다. 최초 단계 주문의 목표 수량을 고정하고 취소·부분 체결 뒤에도 잔량만 처리한다. 실제 목표 수량이 체결되어야 단계가 완료된다.

## SPYM 적립

실제 익절 체결 수량 N, 사이클 기준 단가 P, 실제 매도가 S, 비용 F를 사용한다.

- 전략상 원금: N × P
- 순매도 대금: N × S − F
- SPYM 배정액: min(전략상 원금, 순매도 대금)
- 현금 수익: 순매도 대금 − SPYM 배정액

배정 원금은 체결 다음 거래일부터 SPYM 매수에 사용한다. 1주 미만 잔액은 이월하며 현금 수익은 같은 TQQQ 사이클에 재투자하지 않는다. SMA 전량 매도 대금은 SPYM으로 전환하지 않는다.

SPYM은 장기 보유한다. 연말 전체 손익·외부 손익·비용·환율·취득원가·증권사 귀속 기준과 예상 세금 효과가 검증된 엔진의 절세 조건을 모두 충족하는 경우에만 예외적으로 매도·재매수한다. 대시보드는 세금 판단이나 주문을 수행하지 않는다.

## 화면과 API의 범위

`/strategy`는 위 설명과 현재 상태를 로그인 없이 공개한다. 시세 차트는 TradingView 공식 위젯을 사용하며 엔진의 판단값은 별도 패널에 표시한다. 현재 버전·마지막 평가·완충 폭·만료·사이클·익절 완료/불가 단계는 API가 제공하는 값만 표시한다.

QQQ 종가·SMA·매수/매도 기준선은 같은 평가에 보존된 근거로만 패널에 함께 표시한다. TradingView 차트에 해당 값을 덧그리거나 위젯 시세로 과거 판단값을 재구성하지 않는다.

API의 현재 평가 응답은 실행 모드와 신호 유무에 따라 QQQ 가격·SMA·완충 폭을 생략할 수 있다. 없는 값은 미제공으로 표시한다. 현재 완충 폭을 과거 SMA에 적용하거나 미제공 SMA를 브라우저에서 추정하지 않는다. 시세 차트는 TradingView가 제공하며 엔진 평가 시점과 별도로 표시한다.
